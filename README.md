# 此刻 · ShareTime

为两位好友设计的 Android 生活记录应用。发起邀请、拍照或截图，双方完成后一起查看彼此的此刻。

本软件由CY个人开发。目前版本为 **0.7.2 测试版**，最低支持 Android 8.0（API 26），编译及目标 Android 17（API 37）。

## 下载与安装

- [下载 0.7.2 APK](https://github.com/cyuser199/shareTime/releases/download/v0.7.2/ShareTime-0.7.2-debug.apk)
- [Release 说明与 SHA-256 校验文件](https://github.com/cyuser199/shareTime/releases/tag/v0.7.2)

安装包使用开发签名。已安装此前同签名测试版的手机可以覆盖升级，保留配对和本机历史。联想 Android 11 已验证保留配对；模拟器回到注册页已由用户确认为手动清除应用数据所致。卸载或清除应用数据会失去本机记录。

## 使用方法

**0.7.0** 新增[模式选择与好友群组](docs/friend-mode-0.7.0.md)：默认双人模式，好友模式最多 5 人，两种关系独立保留。好友记录由在线且同意的成员参与，发起后直接开始准备图片，其他成员可随后加入，首次提交锁定参与名单，未参加的人不阻塞。

**0.7.1** 优化[多人图片与时间线](docs/friend-layout-0.7.1.md)：显示本次参与者、人数与图片数，详情支持成员快捷大图及带名字、序号的竖向图片浏览。

**0.7.2** 新增[即时发起与自由排版](docs/friend-layout-0.7.2.md)：多人发起无需再次确认，详情支持竖向、三角和自定义拖动缩放。已部署云端，并通过三设备记录测试。

0.6.3 新增[展示相框](docs/photo-frames.md)：在设置、记录详情或记录大图菜单选择相框样式，直接应用到软件内的图片展示；保存相册仍保留原图。记录图片保持上下竖向展示，等比例完整显示。版本详情见 [0.6.3 说明](docs/release-0.6.3.md)。

1. 两台手机安装 APK，阅读并同意使用协议。
2. 新用户填写昵称并连接默认云服务器；升级用户沿用原身份。
3. 每台设备有固定的 8 位配对码，可长按复制数字或复制包含分享链接的好友口令。好友确认申请后，对方在线则直接配对，离线则显示已发送、等待上线；服务器登记最长保留三天，到期可重新登记原码。可在设置中核对两端的配对安全码。
4. 点击“一起记录”，申请人进入记录准备页。好友可以同意或拒绝；好友离线时，邀请最多等待 24 小时，上线后接收。
5. 双方同意后，每人拍照或截图、预览并确认提交。本轮最多 10 分钟，双方均提交后才会互相展示。
6. 完成记录后，两张图片加密保存在各自手机的时间轴。当天首次完成会播放祝贺动画，点击时间轴标记查看详情。
7. 打开 Material 3 日历，选择日期查看当天记录。详情采用紧凑图片卡片；点开图片，在右上角菜单保存到相册或删除本机整条记录。
8. 设置中可以自选背景图片、恢复默认背景，以及查看协议和后台接收设置。

系统相机由本人操作。屏幕截图每次请求系统授权，授权后有 5 秒切换时间，只截取一帧即停止；也可选择手机已有截图或图片。受保护页面可能无法截图。

当前图片详情改版见 [0.5.0 说明](docs/release-0.5.0.md)。

## 更新与首次权限

同意协议后，首次进入显示通知与可选小窗权限引导，拍照、截图及保存按需授权。启动连接后会自动检查服务器更新，也可在设置中点击“检查更新”。普通更新自动提醒一次，服务器逻辑更新可再次提醒，手动检查不受此限制。默认服务器地址只读，自建服务器入口位于地址框右下方。下载由浏览器完成，安装需按系统提示确认，覆盖安装保留本机数据。

发布接口和本轮验证范围见 [0.4.0 说明](docs/release-0.4.0.md)。0.4.0 已补充 Android 11、16 双机验证，结果与未覆盖项见 [真机补测记录](docs/device-validation-0.4.0.md)。

最新连接与图片展示调整见 [0.5.2 版本说明](docs/release-0.5.2.md)。

## 后台通知

- “保持接收邀请”默认开启（保留已有手动选择），应用会显示持续通知，使用前台服务保持连接，使用每秒心跳检测、断线退避重连和网络变化重连；设置中支持手动重连。连续十秒无服务器回应将重建连接，实际休眠时机受系统限制。
- 支持在系统允许时开机、升级后恢复已开启的接收服务。
- 可选择授予悬浮窗权限，后台收到邀请时显示最多 4 秒的无按钮小窗提醒；锁屏或勿扰状态使用系统通知。
- 设置提供系统通知、省电及应用后台设置入口。建议允许通知横幅、锁屏通知和后台运行，具体选项依手机品牌而定。
- 当前未接入厂商离线推送。强制停止、系统终止进程、深度省电、断网或服务器停机仍可能影响送达，不能保证通知必达。

离线邀请仅在服务器内存等待，服务器重启会清除待处理邀请及未完成记录。双方记录属于同一轮分享，不代表严格同时拍摄；选择已有图片也不能证明内容刚刚产生。

## 隐私与数据保存

- 图片使用 ECDH P-256、HKDF-SHA256 和 AES-256-GCM 端到端加密，服务器不持有手机私钥。
- 服务端只在有上限的内存中暂存中转密文，不将记录图片写入服务器磁盘。双方确认收到、超时或服务重启后清理。
- 本机历史、日期索引和自选背景加密保存在应用私有目录，密钥由 Android Keystore 管理，并排除备份和设备迁移。
- 主动保存到相册的图片是普通相册文件，受相册及其备份设置管理。删除本机时间轴不会删除好友或相册中的副本。
- 服务端业务数据目录保存累计注册设备数与服务签名密钥；待配对的配对码、设备公开信息、申请与待领取证书最长保存三天，成功确认后清理。统计包含重装和测试注册，不等同实际使用人数。
- 配对证书保存在手机。服务重启后可通过重连恢复配对；服务端没有持久身份或撤销数据库，不提供跨重启的全局凭据撤销。
- 尚未进行独立密码学审计。请只与信任的好友配对，并在分享前确认内容。

## 源码与构建

| 目录 | 内容 |
| --- | --- |
| `android/` | Kotlin、Jetpack Compose Material 3 客户端 |
| `server/` | FastAPI / WebSocket 内存中转服务与测试 |
| `tools/` | 构建、部署、设备调试及公网验证工具 |
| `docs/` | 版本、迁移及测试说明 |

Android 使用 AGP 9.3.3、Gradle 9.5.0、JDK 17、Android SDK 37。已有开发环境可通过 Gradle Wrapper 构建：

```sh
cd android
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Windows 使用 `gradlew.bat`。请配置 `ANDROID_HOME` 或本机 `local.properties`。本项目的 Windows 环境准备与构建脚本如下，默认工具目录为 `C:\environment`：

```powershell
py tools/prepare_android_env.py
powershell -ExecutionPolicy Bypass -File tools/build.ps1
```

直接使用 Gradle Wrapper 时，APK 位于 `android/app/build/outputs/apk/debug/`。Windows 的 `tools/build.ps1` 默认在 `D:\codex-build\shareTime` 构建：源码保留原位，Gradle 缓存、临时文件、独立构建目录和检查日志均放到 D 盘，APK 输出到该目录下的 `deliverables/`。可通过 `-BuildRoot` 指定其他构建目录。公开仓库不包含 APK、设备测试截图、登录票据或构建缓存；安装包通过 GitHub Release 分发。

云端连接使用系统信任的 TLS 证书。仓库内保留的旧局域网 CA 公钥仅用于旧地址的兼容配置，无需先部署本地服务器即可构建。

## 云端运维与验证

当前服务为 `sharetime.service`，代码目录 `/opt/sharetime/current`，业务数据目录 `/opt/sharetime/data`。服务以专用低权限用户运行，保持单 worker；Nginx 的 `/sharetime/` 路径转发 HTTP/WebSocket，并关闭该路径访问日志和缓冲。

云主机管理命令：

```sh
systemctl status sharetime
journalctl -u sharetime -n 30 --no-pager
nginx -t
curl --fail https://cyadmin.xyz/sharetime/health
```

本地服务端测试及公网加密闭环验证：

```sh
python -m pip install -r server/requirements-dev.txt
python -m pytest server -q
python tools/smoke_server.py
```

`smoke_server.py` 会在云端注册两个测试身份，验证证书、配对、邀请、双方提交、加密传输和接收确认，会增加累计注册设备数。

`tools/deploy.py` 是原局域网部署工具，`tools/migrate_cloud.py` 是依赖原开发电脑登录配置的一次性迁移工具；它们不应作为通用云端首次部署命令。云端配置及回退要求见 [迁移说明](docs/cloud-migration.md)。
