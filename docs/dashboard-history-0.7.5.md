# 历史数据与隐私说明 v6（0.7.5）

查看器支持统计日期选择和回到今天。每日汇总保留于 stats-history.json；管理员可查看已同意 v6 的用户按日保存的昵称、手机型号、个人次数及每日设备标签。访客接口只返回汇总，不提供历史个人信息。当前在线及累计注册始终明确标为当前值，不伪造历史时刻状态。

客户端同意 v6 后在原身份连接时上报 privacyVersion=6，服务器只为这些用户保留历史明细。旧客户端或未同意新版的用户仍在跨日清除明细；历史每日汇总不含身份信息。无需重新注册或配对。v6 说明明确当日及以后数据持续保留至管理员删除，删除个人统计可联系开发者处理；不保存记录图片到磁盘。跨日归档为原子写入、权限 600，重启后继续可查。

历史可用范围：2026-10-31 的汇总由既有备份快照恢复，明确标记可能不完整，不恢复旧协议个人明细。新的完整每日归档从启用后累计；缺失日期返回无保留数据。

验证：服务端 34 项测试通过，包括跨日归档、重启恢复、旧协议清除、新协议明细保留、访客隔离、日期校验和持续在线跨日。云端浏览器验证访客及管理员切换日期、快照说明、回到今天及手机宽度布局。Android 编译、11 项单元测试、lint、APK 签名与对齐通过。当前没有 ADB 测试设备，0.7.5/v6 真机同意及跨日现场验证待设备接入；跨日逻辑已用可控时钟测试。
