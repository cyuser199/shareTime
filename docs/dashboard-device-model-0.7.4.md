# 服务端查看器：用户名与机型（0.7.4）

此为 0.7.4 实现记录。0.7.5/v6 新增同意后的历史明细保存，见 [历史数据说明](dashboard-history-0.7.5.md)。

现有管理员页面 /sharetime/admin 增加“注册手机型号”列，保留用户名、每日完成次数及在线状态。旧客户端未提供型号时明确显示“未上报”。型号是已登录客户端自报的品牌与 Build.MODEL，用于兼容性排查，不用于身份验证。

- 新版客户端同意 v5 隐私说明后，建立 WebSocket 时上报品牌与型号，不收集 IMEI 或设备序列号。不修改签名身份、配对安全码、群组成员身份或旧配对凭据。
- 服务端仅在每日统计中保存机型，沿用每日 HMAC 设备标签，个人明细北京时间跨日清除；断线或服务重启仍能显示当日已有明细。
- 双人、好友两种连接都支持；未配对在线设备跨日后的昵称和机型从当前连接信息补齐。缺少机型的旧凭据不会覆盖已上报信息。
- 型号最多 80 字，忽略无效类型和超长输入；界面通过 textContent 插入，用户名与机型不作为 HTML 执行。
- 管理页及统计 API 继续要求管理员登录，返回 no-store；公开统计接口不提供个人信息。窄屏表格可横向滚动。
