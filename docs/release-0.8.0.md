# 此刻 0.8.0 测试版

- 提交个人记录后可以返回主页，本轮在服务器内存最多保留 24 小时，其他好友可稍后上线、同意并记录。
- 双人可先于离线好友提交；多人按发起时群成员分别加密，已提交成员逐步交换内容，后提交者补齐到同一条历史，保留原日期和次数。
- 可返回进度，暂存后切换模式；新式多人轮次需要参与者更新。照片和临时密文不写入服务器磁盘，超时、整轮送达或服务器重启后清理。
- 在线判断更及时：约 15 秒无应用消息会移除连接。后台重连退避缩短、网络恢复检测、服务连接检查、通知重连操作及实际状态显示；图片处理不再阻塞心跳。
- 后台收到补交内容会提醒，已主动删除的本机记录不会被补齐重新创建。
- 隐私说明更新为 v7，需要使用者本人阅读并选择。

验证：40 项服务端测试，Android 构建、11 项单元测试、lint；云端隔离 TCP/WebSocket 流程及 15 秒空闲断线检查通过。当前无 ADB 手机，实际息屏接收、厂商清理和客户端联调待设备接入。系统强制停止、深度省电及未接入厂商推送的限制仍存在。
