# 后台接收优化（0.5.1）

- 删除客户端重复的 WebSocket 协议心跳，应用心跳由 25 秒改为 60 秒，仅在连接存活时运行；断线与主动停止时取消任务。
- 默认网络变化由 Store 统一监听，前台及后台复用同一连接；移除服务内重复回调。断网时取消连接和重试，网络恢复或切换时立即连接。
- 连续失败使用带随机间隔的指数退避，最大等待 5 分钟；收到服务器状态后重置失败次数，避免仅握手成功就不断快速重试。
- 云端 WebSocket 协议保活同步改为 60 秒，超时 30 秒；保留现有 90 秒应用空闲检测及代理超时，兼容旧客户端。
- 不使用常驻唤醒锁、精确闹钟或定时拉取消息，保留用户主动开启的低优先级前台服务通知。

验证：Android 构建、单元测试（含长时间失败退避边界）、Lint 通过；服务端 13 项测试通过；云端服务健康检查通过。联想 Android 11 和 Android 9 模拟器已覆盖安装并验证连接；模拟器后台前台服务处于运行状态。

用户选择保留两端现有的不同配对，未进行双机邀请送达测试。长期息屏耗电、深度休眠送达与真实断网恢复尚未完成设备验证，不能据此承诺耗电数值或通知必达。系统休眠、强制停止及厂商后台限制仍可能延迟接收；后续可接入系统或厂商推送进一步减少长连接成本。
