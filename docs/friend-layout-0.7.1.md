# 多人图片与时间线（0.7.1）

好友时间线使用细竖线和卡片分组，显示完成时间、参与人数、图片张数、头像缩写及成员名字。摘要来自本次保存的记录，不采用当前群成员列表，因此成员退出后历史仍保持原有参与者。旧好友记录在首次读取时从加密记录补齐摘要，并缓存到加密索引；摘要缓存失败不会阻止读取原历史。

多人详情采用独立摘要区，显示时间、图片数及可横向滑动的成员入口；点击成员可直接查看对应大图。照片保持竖向排列，左上角显示名字与当前序号。三张以上使用适合滚动浏览的大图高度，两张记录继续按屏幕空间分配，均保持原比例完整展示。

验证：D 盘最终构建、客户端单元测试及 Lint 通过。两台设备已安装 0.7.1（16）。使用两台设备和一个合成图片客户端生成三人记录，两台设备均完成解密和本机保存，实际检查时间线的“2 人 · 2 张”“3 人 · 3 张”、详情中的三张图片及成员快捷大图。旧记录摘要迁移通过实际升级验证。临时测试成员已从群组移除，测试记录保留在本机。

五人满员布局与超大系统字体尚未逐项设备验证。
