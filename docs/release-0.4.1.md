# 0.4.1 · 紧凑图片详情

- 图片详情移除大标题、外部保存/删除按钮及不相关的日历、设置入口。
- 时间与记录次数合并成一行，两张完整图片使用圆角卡片显示，图片上仅保留“我”和好友昵称标签；不裁切原图，缩小边距和卡片间距。
- 点开任意图片，在右上角“图片操作”菜单保存图片或删除本机整条记录。删除仍需二次确认，并明确会删除本机这次记录的两张图片。
- 保存后返回详情显示保存结果。大图支持关闭返回。

APK versionCode 7，沿用原开发签名，覆盖安装保留配对与历史；通过服务器更新接口及 GitHub Release 分发。
