# 本地展示相框（0.6.3）

设置 → 相框样式，或记录详情右上角“相框”、记录大图菜单“相框样式”。可选无相框、简白、墨黑、暖纸、胶片，选择保存在本机并应用到记录详情和大图。相框仅用于展示，保存相册仍保存原始记录图片；无需导出副本才能看到相框。

图片保持上下竖向展示，名字以半透明小标签显示在图片左上角，按实际可用屏幕高度分配图片空间，压缩外围留白，等比例完整显示。相框统一四边宽度，展示不裁圆角；胶片装饰按左右镜像、上下等距排列；简白和暖纸使用轻细外轮廓线。图片不裁切、不拉伸。

实现使用 PhotoFrames 原生绘制与 Compose 展示，无新增编辑器依赖。此前调研的 PhotoEditor（https://github.com/burhanrashid52/PhotoEditor）偏完整编辑器，FramedImageView（https://github.com/ANPez/FramedImageView）偏固定框展示，未复制其代码。

0.6.3 验证：构建、单元测试、Lint 通过；两台设备已安装并核实版本。使用模拟器现有第 1 次记录检查：名字位于各自图片左上角，两张图上下排列，均完整落在一页内；相同图片显示高度从约 597 像素扩大到 723 像素。
