# 异步记录与后台连接（0.8.0）

新客户端发起记录时选择异步协议。提交后自动返回主页，也可主动返回或稍后再决定；原轮次由服务器内存继续维护，最多 24 小时。主页可返回进度，暂存后可以切换独立模式，切回时重连恢复原轮次。每个双人关系或好友群组同时保留一轮，新开一轮需等待当前完成、超时或发起人结束。

双人：发起人可在对方离线、未同意时先提交密文，接收者上线同意并提交后双方交换。好友：收件范围固定为发起时群成员，发起时为所有原成员各自加密，但只有已同意且已提交的成员可读取其他已提交者的副本。两人提交即可保存部分记录，后来成员补交时按版本号更新同一条本机记录，不新增次数或改写初次归档时间。新入群者不自动获取已发起轮次。最后版本全员确认后清理；拒绝者、未提交者不能提前查看。新式好友轮次需要参与者使用协议 2 客户端，旧客户端明确提示更新；旧式记录继续兼容。

服务器不将图片或中转密文落盘，重启会清理未完成轮次；接收端已保存的内容保留。双人及群组中转共享 128 MiB 上限。首次达到两人提交计一轮完成，稍后补交成员只增加自己的参与次数，不重复增加整轮计数。本机已删除的记录不因后续补齐重新出现；自定义排版在新增图片时保留已有位置。

后台：沿用用户可关闭的静默前台服务，START_STICKY，明确不随最近任务划除而主动停止；心跳保持每秒一次，10 秒无回应重建连接；重连退避上限 30 秒，服务每 20 秒检查并在网络验证恢复时重连。消息串行处理队列有上限，Pong 不排队等待解密、图片处理或磁盘写入。通知显示实际服务器连接状态，并提供重连操作。新内容或补交内容到达后台时通知提醒。

没有采用隐藏通知、常驻唤醒锁或反复拉起进程的做法。尚未接入小米等厂商推送；Android 深度休眠、厂商清理、强制停止及断网仍可能中断接收，恢复后自动同步仍在期限内的轮次。设备当前只监听所选模式的实时邀请，另一模式在切回时同步。

隐私说明 v7 解释异步 24 小时等待、逐步展示、原群成员收件范围、服务器内存保留及重启清理。历史统计沿用 v6 同意规则。

验证：40 项服务端测试通过，包含断线后晚加入、版本增量、隐私隔离、重连、过期清理、双人离线预提交和共享内存预算；Android 构建、11 项单元测试与 lint 通过。云端使用临时隔离目录与回环 TCP 进行真实 WebSocket 流程，验证离线上传、后来补交、最终确认清理，以及停止应用消息约 15 秒后关闭连接；不写入正式用户统计。当前没有 ADB 设备，v7 确认、客户端时间轴更新及真机息屏/厂商清理恢复尚待连接设备验证。
