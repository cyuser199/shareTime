# 此刻 0.6.3 测试版

- 新增软件内展示相框：无相框、简白、墨黑、暖纸和胶片，可在设置、记录详情或大图菜单中选择，本机记住样式。
- 相框四边等宽，胶片装饰对称，不进行不一致的圆角裁切。相框仅用于展示，保存相册仍为原始图片。
- 记录详情保持上下竖向排列，名字移入各自图片左上角，使用半透明小标签。
- 按实际可用屏幕高度分配图片空间，缩小页头和图片间距；图片等比例完整显示，不拉伸、不裁切。

验证：Android 构建、单元测试及 Lint 通过；联想 Android 11 和 Android 9 模拟器均已覆盖安装。模拟器现有记录已检查：两张图片在一页完整展示，名字位置正确；同一记录的图片高度从约 597 像素增至 723 像素。此前端到端验证双方在线及记录邀请送达。

本版本为普通客户端更新，自动提醒一次；可在设置中手动检查更新。小米推送尚未接入，后台持续服务仍保留必要的静默通知。长期息屏耗电和深度休眠送达尚未完成验证。
