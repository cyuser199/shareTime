# 此刻 0.7.2 测试版

- 新增独立好友模式，最多 5 人，保留原双人配对与历史。首次进入可选择模式。
- 多人发起后立即记录，不需要发起人再次确认；其他成员自行加入。至少两人可提交，首次提交后停止加入，未加入者不阻塞。
- 多人时间线显示成员、人数和图片数；详情保留竖向，增加三角、自定义拖动缩放，按本机每条记录保存布局。
- 相框只用于应用内展示，图片保持比例，保存相册为原图。
- 优化本机加密大图读写，保存后回读校验；已提交图片加密暂存，重启后可继续保存。
- 读取异常提供明确提示和重试入口。

验证：服务端 20 项测试，Android 编译、单元测试、lint、签名验证通过；联想、小米、模拟器完成三人记录，模拟器验证提交后重启恢复。
