# 0.8.0 三设备验证

日期：2026-11-01。客户端 0.8.0（21），云端 HTTPS 服务；三台独立 Android 9 / API 28 模拟器，分辨率分别为 1080×1920、720×1280、1440×2560。使用者已自行接受 v7 协议。

使用原好友群组进行测试，原成员和双人配对保留；另外两个测试成员仍留在群组。图片均为人工生成的 A/B/C 标记测试图。截图及 UI XML 仅存于本地忽略目录，不随本文提交。

| 场景 | 实际结果 |
| --- | --- |
| B 应用停止，A 发起并提交 | A 自动返回主页，显示服务器继续等待好友；云端显示 B 离线 |
| C 未同意加入 | 仅看到邀请、已加入人数及成员名，没有收到记录图片 |
| B 重开应用后加入 | 收到既有轮次，能选择图片并提交；A/B 均出现 2 人、2 张的一条时间线记录 |
| B 提交后仅重启应用 | 轮次仍存在，显示已提交；本人预览恢复，已保存的 2 张记录保留 |
| B 返回进度再返回主页 | 能正常查看已提交状态并停留在主页 |
| C 延后加入并提交 | A/B 原记录更新为 3 人、3 张，原 13:28 时间及第 1 次序号保留，没有重复条目；C 首次保存显示本地接收时间 13:29 |
| 图片实际显示 | A 详情的三角排版中，三张 A/B/C 测试图片与姓名对应正确，已人工检查截图 |
| 使用统计与在线情况 | 管理接口显示三个测试用户均在线，各计 1 次记录 |
| 发起人结束测试轮次 | 三台恢复“一起记录”，本机 3 张历史保留；群组与原配对保留 |

本轮恢复连接后的测试没有修改网络设置或接管 Windows 桌面，仅按授权停止和重开 B 的应用。此前关闭的 C 移动数据仍保持关闭，用户明确要求保持当前状态；其 Wi-Fi 正常连接。

范围限制：这是三个模拟器的应用内流程验证；未执行息屏、断 Wi-Fi、厂商清理、Doze 或最新 Android 真机测试，不能据此保证这些环境的后台送达。停止应用期间不会实时接收，重新打开后的恢复已通过。本轮没有等待真实 24 小时超时；超时及服务重启语义由服务端测试覆盖。
