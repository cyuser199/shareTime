# 双人固定配对码登记修复

日期：2026-11-06。服务端修复，现有 0.8.0 / 0.8.1 手机无需更新 APK。

## 已确认的问题

固定码保存在手机，服务端的待配对登记最长保存三天。原流程在以下情况下会出现“码仍正确，但配对失败”：

- 三天后重连仍携带旧登记票据，服务端沿用过期时间，无法重新建立登记。
- 申请人自己的登记已过期，即使好友登记有效，也会误提示“请对方重新登记原码”。
- 对方持续在线超过三天时，登记被定时清理，服务端无法凭其在线身份补登记。

## 修复

- 认证设备重连时，如果旧登记已经过期，用相同固定码开启新的三天登记；尚未过期的登记不因重连延长。
- 输入好友码时，仅为当前在线、已认证的设备补登记。申请人登记过期自动补齐；在线好友的登记过期也可补齐。
- 离线过期登记不会自动恢复，离线设备仍需打开应用。离线申请期限保持为双方登记期限中的较早时间，不延长既有待处理申请。
- 分别提示本人已配对、频率限制、自配对、位数错误、对方登记不存在；保留对方已配对及登记冲突检查。

验证：52 项服务端测试通过，新增三天后双方仍在线、申请人过期但好友离线登记有效、过期票据重连，以及有效票据重连不延期的检查。已部署云端，公网健康检查正常；签名密钥与管理凭据保持一致。

## 修复前的相关提示

固定码流程：

- 配对码未登记或登记已过期，请对方重新登记原码
- 已有配对，或尝试次数过多
- 对方已配对
- 无效配对登记
- 配对码暂时冲突，请稍后重新登记
- 服务器登记已满，请稍后重试

客户端或共用处理：

- 尚未连接服务器，请检查网络后重试
- 当前没有可用网络，恢复后会自动连接
- 消息格式有误，请重试
- 消息格式错误，请重新连接后重试
- 消息处理失败，请重新连接后重试
- 操作过于频繁，请稍后再试
- 服务器繁忙

旧版临时配对流程及凭据检查还包含：

- 请先解除现有配对
- 配对码无效或已过期
- 对方不在线或已配对
- 已有配对确认，请稍后重试
- 配对请求已失效
- 设备已配对
- 无效配对凭据

部分握手错误只会断开连接，未必直接显示内部错误文字。用户这次遇到的具体提示仍待回忆确认；已复现的过期问题不代表已经确认是此次故障的唯一原因。
