# 0.5.0 测试版

- 每台设备使用固定配对码，口令及分享链接绑定该码。
- 支持离线配对申请；对方上线后自动完成，在线时直接配对。请仅向信任的好友分享配对码。
- 待配对登记、申请及待领取配对凭据最长保留三天，成功确认后清理；服务器不持久保存记录图片。
- 默认服务器地址只读、浅色显示，输入框与昵称框等宽；自建服务器入口放在框下方右侧。
- 普通更新自动提醒一次，服务器逻辑更新可再次提醒。本次为服务器逻辑更新。
- 修正配对成功时偶尔出现的未连接提示；Windows 构建默认使用 D 盘。

验证：Android 构建、单元测试、Lint 通过；服务端 13 项测试通过。联想 Android 11 与 Android 9 模拟器验证了离线等待、上线自动配对，服务器配对登记清理为零。更新后的排版已在两端检查。

验证范围：双机完整拍摄、交换与时间轴回归尚未完成，本包继续作为测试版发布。模拟器回到注册页已由用户确认为手动清除应用数据所致，不属于覆盖升级缺陷。
