# 0.5.2 连接与展示调整

- 用户选择优先持续接收：保留必要的低优先级前台服务通知，显式静默且只提醒一次；好友邀请仍使用独立的高优先级通知。
- 每秒发送应用心跳，连续十秒未收到服务器消息即取消失效连接并进入退避重连。设置页增加手动重连；该操作会重建连接，无网络时等待系统网络恢复事件。
- 新用户默认开启保持接收邀请；保留已有的明确开关选择，不读取电量来主动关闭服务。系统休眠和后台限制仍适用。
- 历史详情两张图片按屏幕高度分配更大的显示区域，使用 Fit 等比例完整显示，继续支持点击查看全屏图片。

验证：D 盘最终构建、客户端单元测试、Lint 和服务端 13 项测试通过；两台设备均已覆盖安装。Android 9 模拟器手动重连后恢复服务器已连接状态。后续经用户授权将两台设备互相重新配对，均显示好友已连接，并验证联想发出的邀请正常到达模拟器；图片区域尚未使用完整双机记录进行视觉回归。

每秒心跳比 0.5.1 的六十秒心跳更耗电和流量，不代表可以每秒唤醒处于深度休眠的手机。
