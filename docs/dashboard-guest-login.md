# 访客入口与网页登录

入口 /sharetime/admin 为公开欢迎页，包含管理员登录表单和访客查看按钮。访客只能获取今日用户数、记录轮次、在线设备数及累计注册数；用户明细 API 仍需认证，访客端不请求或持有昵称、机型、设备标签。

管理员网页登录使用 Secure、HttpOnly、SameSite=Strict 会话 Cookie，有效期 8 小时，退出后清除。会话签名绑定当前密码摘要，修改密码会使旧会话失效。密码不进入 URL、不保存到前端存储；登录限速并拒绝跨来源请求。保留 Basic Auth 的受保护 API 兼容方式，但不再发送 WWW-Authenticate 挑战，页面不会弹出浏览器原生密码框。

云端管理员密码已按使用者要求更换，仅保留服务器密码摘要；本机既有登录票据同步更新，代码和文档不记录密码。

验证：服务端 30 项测试通过；真实云端浏览器验证欢迎页、访客不暴露明细、管理员表单登录、刷新后会话保留、退出失效、390px 窄屏布局通过。部署前备份业务数据与旧认证配置，签名密钥校验不变，健康检查正常，旧密码登录失败。
