# 海报导出（0.7.3 / 18）

记录详情新增“一键导出海报”，在本机生成 JPEG 并复用相册保存流程。双人记录可导出竖向海报；好友记录按当前竖向、三角或自定义布局导出。原照片和加密记录不变，不上传海报。

- 标题、记录日期和小时（按本机时区，不显示分钟）、成员名字、当前展示相框。
- 自定义布局使用点击导出时的位置、大小和图片顺序快照；编辑器与导出共用 PosterLayout 坐标与等比例适配算法，保留重叠顺序。
- 导出整个画布，独立于当前滚动位置；上方增加时间标题，下方增加简短落款。
- 最大宽度 1080px，高度最多 8192px；高海报等比降低分辨率，逐张处理并释放位图。生成期间禁止重复点击，失败显示提示。
- Android 8/9 沿用按需存储权限，Android 10 及以上通过 MediaStore 保存至 Pictures/ShareTime。

验证：D 盘 assembleDebug、testDebugUnitTest、lintDebug 通过，APK 签名及 zipalign 通过。新增 4 项测试覆盖自定义坐标跨分辨率保留、位置边界、长宽比、竖向适配、时区及小时格式。联想 Android 11 覆盖安装后，实际完成自定义拖动缩放、三角和竖向三种导出，确认相册生成 JPEG；拉取成品检查自定义坐标、全部三张图片与小时标题。

本次仅构建和安装客户端，未发布 GitHub Release 或修改云端更新清单。Android 8/9 导出的实际权限弹窗尚未在本轮设备验证。
