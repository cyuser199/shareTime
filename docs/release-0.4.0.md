# 0.4.0 测试版

- 配对页面生成配对码后，长按大号配对码复制原始数字；也可点击“复制好友口令”，将带有 SHARETIME 标记的文本发送给好友。口令沿用 5 分钟有效的配对码，不包含账号密钥。
- 未配对时，在应用前台识别剪贴板口令，确认后发出配对申请，生成端仍需确认；也可手动点击“读取剪贴板好友口令”。忽略后相同口令不反复提示（当前页面生命周期内）。不读取后台剪贴板，不上传无关内容。仍只支持两人配对。
- 同意更新后的协议后，首次显示统一权限引导，包括系统通知、小窗权限入口。通知和小窗权限可拒绝；相机使用系统相机无需本应用申请相机权限，截图和旧版相册保存继续按需授权。
- 邀请小浮窗改成约 300dp 宽的纯提醒，无操作按钮、无需确认、不抢焦点，4 秒自动消失，尊重锁屏和勿扰设置。
- 启动连接后自动检查服务器版本，设置中也可点击“检查更新”。有更高 versionCode 时显示版本说明；用户点击下载后由浏览器下载，按系统提示安装。应用不静默安装，不提前申请安装来源权限；覆盖安装需要同一签名。

## 更新发布

接口：

- `GET https://cyadmin.xyz/sharetime/updates/latest`
- `GET https://cyadmin.xyz/sharetime/updates/apk/{sha256}`

版本清单含 `versionCode`、`versionName`、`notes`、`apkUrl`、`sha256` 和 `size`。尚未发布时返回 `versionCode: 0`；损坏或缺少 APK 的清单返回 503。APK 按 SHA-256 内容地址保留，便于正在下载旧版本的用户完成下载。

服务器从 `/opt/sharetime/updates/latest.json` 读取清单，无需为每次发版重启。APK 属于软件发布文件，与好友记录图片分开保存。服务器没有开放写入接口，管理员通过 SSH 发布：

```sh
python tools/publish_update.py --host YOUR_SERVER --user root --key YOUR_SSH_KEY --apk deliverables/ShareTime-0.4.0-debug.apk --code 6 --version 0.4.0 --notes "本次更新说明"
```

脚本使用现有 SSH 密钥或 agent、严格校验服务器身份，上传完成后校验远端 SHA-256，再原子切换版本清单。需要先部署包含更新路由的 `server/app.py`；当前云端已部署。管理员应只发布相同应用 ID、相同签名的 APK，versionCode 必须递增。客户端通过 HTTPS 获取更新并调用浏览器下载；不会自行校验浏览器下载后的文件散列，系统安装器负责签名与升级检查。

## 验证范围

Android 构建、单元测试、Lint；服务端 9 项测试；公网版本清单与 APK 下载后 SHA-256 校验。口令测试覆盖标记识别、普通数字不识别、过长数字和尾随字符拒绝。

本轮 ADB 无设备，未进行新功能真机验证。此前版本在 Android 11、16 的结果不替代本轮测试。未配对用户首次打开会受 Android 前台剪贴板访问限制，系统可能显示读取提示；首次安装的系统权限和浏览器安装 APK 界面取决于手机系统。


发布结果：0.4.0（versionCode 6）已发布至云端更新接口；公网重新下载 APK 后，文件大小与 SHA-256 均与本地一致。APK 签名与 ZIP 对齐检查通过。Android 5 项单元测试、服务端 9 项测试通过，Lint 无错误（仅建议警告）。本轮依然没有连接真机。
