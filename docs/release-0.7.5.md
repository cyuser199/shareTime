# 此刻 0.7.5 测试版

- 新增海报导出：沿用竖向、三角或自定义布局，保留图片位置、大小、相框和名字，标注日期及小时，保存到本机相册。
- 管理查看器新增网页登录、访客汇总入口、用户名和手机型号、按日期查看历史及回到今天。
- 服务端保存每日汇总；同意新版协议的用户个人明细按日保存，访客不能读取。
- 隐私说明升级 v6：明确品牌型号与每日统计用途、历史个人明细保存至管理员删除、删除联系途径。旧版用户仍按旧规则清除个人明细。更新后需使用者自行阅读并选择是否同意。
- 已同意历史保存的手机持续在线跨日时，无需重新连接即可延续统计。

验证：34 项服务端测试，Android 构建、11 项单元测试、lint、APK 签名及对齐通过；云端浏览器登录、退出、访客隔离、历史日期与手机布局通过。海报三种排版已在此前联想测试验证。本轮暂无 ADB 设备，v6 真机确认等待用户更新后完成。

旧备份只能恢复部分历史汇总，页面会提示可能不完整；已清除的旧协议个人明细不会补存。
