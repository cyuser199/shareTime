# 0.7.2 测试版

- 多人邀请直接进入记录，发起人不再二次确认。原群组离线成员在本轮结束前上线也可收到邀请。
- 好友自行选择加入，至少两人才可提交。第一次有效提交锁定参与名单；之后不能加入，避免已加密图片出现收件人不一致。未参加者不阻塞，也不能获取图片。
- 详情保留竖向默认，新增三角排版和自定义画布。自定义可选择图片、拖动、调节大小和重置，按本机每条记录记住布局；不裁剪、不拉伸，不改变相册原图。
- 读取失败显示重试入口；新记录写入后先回读校验，再写入时间轴和确认接收。

验证：服务端 20 项通过；Android 构建、单元测试、lint、APK 签名校验通过。联想 Android 11、小米 Android 16、模拟器 Android 9 完成三人记录，三端均保存 3 人 3 张。模拟器在提交后强制停止并重新打开，自己的图片仍能恢复并归档。联想验证三角、自定义拖动、缩放及退出详情后恢复布局。

本地大图加密改为 8 KiB 分块处理，写入后回读认证；已提交图片本机加密暂存，归档或主动结束后清理，残留暂存超过 24 小时在下次启动清理。

已知问题：上一轮模拟器 23:35 的单条记录出现 AEADBadTagException，其他旧记录及两台真机同轮记录可读取。原文件保留；尚未确认根因或恢复该文件。回读校验用于阻止新失败记录被确认为已保存；分块处理后的新记录已在模拟器完成验证。
