# 真机验证清单

至少需要两台手机。优先 Android 17，再覆盖 Android 8 与不同厂商系统。模拟客户端测试不能替代下列检查。

| 场景 | 验证结果要求 |
|---|---|
| 首次安装、注册 | 内置 CA 验证通过，无全局信任修改；拒绝通知仍可使用应用 |
| 配对 | 输入错误、过期、自配对、拒绝确认均无法绑定；两端安全码一致 |
| 邀请 | 发起人直接进入准备页；接收人同意、拒绝和超时行为正确 |
| 同时发起 | 合并为同一轮；不会卡在两个相互等待的会话 |
| 相机 | 系统相机打开、取消、前后摄像头、竖拍/横拍，方向正确 |
| 截图 | 每次授权；取消授权、整屏/单应用、切换目标、受保护页面；截一帧后停止服务 |
| 系统选图 | Android 8 回退选择器，新版 Photo Picker；无需整个相册权限 |
| 双端提交 | 一方提交后不展示对方内容；双方提交后解密显示；重试不覆盖已提交图片 |
| 保存 | Android 8 存储权限允许/拒绝；Android 10+ MediaStore 保存；相册可实际打开 |
| 系统栏 | Android 17 手势导航、三按钮导航；透明栏图标对比正确；按钮不被遮挡 |
| 布局 | 刘海/打孔、横屏、分屏、大字体、深色模式、键盘弹出，内容可滚动 |
| 后台通知 | 两端锁屏、返回桌面、保持接收开关、关闭通知、厂商省电、强制停止 |
| 断线 | Wi-Fi 切换、服务器暂时不可达、上传中断，重连后状态一致 |
| 生命周期 | 拍照/截图/授权期间旋转或系统回收；旧轮结果不进入新轮 |
| 解除配对 | 双方在线、一方离线、服务重启后重连；已解除的一方不被旧证书恢复绑定 |
| 清理 | 结束后缓存清除；服务端只留计数/密钥；主动保存的相册图片仍保留 |

后台通知是否可靠必须记录具体品牌、型号、Android 版本及电池设置，不笼统写成所有设备均可靠。
