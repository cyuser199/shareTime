## 运维与回退

`systemctl status sharetime`；`nginx -t`；`curl --fail https://cyadmin.xyz/sharetime/health`。

服务器图片仍仅在内存中暂存加密内容，历史在手机。基础设施密钥和统计位于 `/opt/sharetime/data`，不上传到代码仓库。云端已有新注册后，不能直接启动旧统计接管；回退须先停止云端、同步最新统计与签名密钥，再切换手机地址与 TLS 配置。

此迁移未接入厂商离线推送，强制停止和深度省电仍会影响提醒。0.3.0 新增的离线等待、协议和可选悬浮窗功能一并包含；联想 Android 11 已实际收到高优先级横幅和悬浮卡片，开机恢复及长期待机仍待后续验证。
